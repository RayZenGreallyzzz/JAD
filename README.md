# Phoenix Starship Builder (JAD)

Автономный модульный конструктор космических кораблей для Android.

## Цель

Собирать корабли из каркасов и белых модулей, устанавливать броню, красить детали, проектировать интерьер, запекать **только статический корпус** и затем добавлять отдельно управляемые турели, лазеры и двигатели.

## Принципы

- Исходный редактируемый проект JSON всегда сохраняется; запекание не уничтожает модули.
- Подвижные механизмы остаются отдельными узлами и не объединяются с корпусом.
- Привязки рассчитываются геометрически, без приблизительного сдвига «на глаз».
- Работа офлайн на Android; экономный рендеринг с учётом устройств с 4 ГБ ОЗУ.
- Экспорт GLB для геометрии и JSON для игровых параметров.

## Этапы

1. Базовый 3D-редактор: каркасы, модули, привязка и покраска.
2. Локальное сохранение, отмена/повтор и запекание статических частей.
3. Подвижное вооружение, двигатели и режим испытаний.
4. Палубы, интерьер, системы корабля, валидация конструкций, GLB + JSON.
5. Сборка и испытания APK на реальном Android.

Статус: ранний прототип. Не следует считать полноценную физику, корректное объединение мешей, боевую логику и APK готовыми до отдельных тестов.


## Что уже работает в первом прототипе

- 38 параметрических модулей, четыре каркаса и пустой проект.
- Автономный 3D-просмотр на Canvas без CDN; вращение и масштабирование касанием.
- Координаты XYZ, повороты 0/90/180/270°, привязка по выбранной грани с учётом поворота.
- Ограниченная проверка пересечений, копирование, удаление, отмена и повтор.
- Цвет каждой детали, окраска всей брони, импорт и экспорт проекта JSON.
- Кеширование статической геометрии в редакторе; при экспорте GLB неподвижные треугольники группируются по материалу, а турели и другие системы остаются отдельными узлами.
- Экспериментальный режим испытаний: перемещение корабля, поворот стволов и визуальный лазерный выстрел.

**Пока не реализованы:** физика столкновений кораблей, баллистика, расчёт энергосистем, удаление внутренних скрытых поверхностей, полноценные разрезы палуб и анимированные двери. «Запекание» в редакторе пока создаёт кеш треугольников, а не оптимизированный по топологии единый водонепроницаемый меш. Для итоговой игры понадобится отдельная проверка коллизий, нормалей и LOD.

## Получение Android APK

1. Откройте вкладку **Actions** в этом репозитории.
2. Выберите **Android Debug APK** и последнюю успешную сборку.
3. В разделе **Artifacts** скачайте `PhoenixStarshipBuilder-debug`.
4. Распакуйте архив и установите `app-debug.apk` на планшет.

APK собирается на GitHub Actions и работает без сети после установки. Проекты и GLB сохраняются в `Downloads/PhoenixStarshipBuilder`. Сборка рассчитана на Android 10 и новее. Экспортированные GLB содержат геометрию и структуру узлов; логику стрельбы игра должна реализовать отдельно.

## Проверки

`node --test tests/*.test.cjs`

Эти тесты проверяют библиотеку модулей, пресеты, геометрию, соединение и структуру GLB. Они не заменяют испытаний в WebView на реальном устройстве.

## Запуск без установки APK

Содержимое папки `web/` — автономное веб-приложение: откройте `web/index.html` в современном браузере. На Android удобнее использовать APK, чтобы корректно сохранять файлы через системную папку загрузок.
