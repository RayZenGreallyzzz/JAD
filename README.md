# Phoenix Starship Builder (JAD)

Автономный модульный конструктор космических кораблей для Android.

## Цель

Собирать корабли из каркасов и белых модулей, устанавливать броню, красить детали, проектировать интерьер, запекать **только статический корпус** и затем добавлять отдельно управляемые турели, лазеры и двигатели.

## Принципы

- Исходный редактируемый проект JSON всегда сохраняется; запекание не уничтожает модули.
- Подвижные механизмы остаются отдельными узлами и не объединяются с корпусом.
- Привязки рассчитываются геометрически, без приблизительного сдвига «на глаз».
- Работа офлайн на Android; экономный рендеринг с учётом устройств с 4 ГБ ОЗУ.
- Экспорт GLB для геометрии и JSON для игровых параметров.

## Этапы

1. Базовый 3D-редактор: каркасы, модули, привязка и покраска.
2. Локальное сохранение, отмена/повтор и запекание статических частей.
3. Подвижное вооружение, двигатели и режим испытаний.
4. Палубы, интерьер, системы корабля, валидация конструкций, GLB + JSON.
5. Сборка и испытания APK на реальном Android.

Статус: ранний прототип. Не следует считать полноценную физику, корректное объединение мешей, боевую логику и APK готовыми до отдельных тестов.
